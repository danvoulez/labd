# Same Lab, same map — a human and an LLM

Two flows over the **same Lab directory**. The human drives the CLI; the LLM
drives the MCP read surfaces and proposes draft Acts. They see identical JSON.

- `human-flow.sh` — a developer/scientist opens a Lab, writes, schedules, runs a
  bench, inspects proof, and learns.
- `llm-flow.md` — how an LLM/agent consumes the same read-models and proposes
  Acts under grants, without ever deciding.

The contract behind both is `docs/SURFACES.md`.
