# foundation (reference, not runtime truth)

LogLine Foundation is the protocol reference: Act form, canonicalization, hash /
signature, conformance, governance. It is **referenced**, not promoted as Lab Kit
runtime truth (Operator §11). The Lab Kit `logline-act` crate implements a
standalone canonicalization recovered from the Foundation `status` crate; the
vendored Foundation tree itself was kept raw in the source fruits, not copied.
