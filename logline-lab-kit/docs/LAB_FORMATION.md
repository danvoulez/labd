# Lab Formation

A Lab is an operational institution for studying LogLine through Acts (FINAL §8).
The basics form a Lab with only an **identity + profile** — no pack required.

Formation cycle (FINAL §8.2): start → load reference → select profile → (load
pack) → write first candidate → admit first valid Act → run a study bench →
produce evidence → produce a report → learn the next action → run conformance →
export a comparable example.

- Lab host: `crates/logline-lab-labd` (`Lab::init`).
- Manifest: `schemas/lab-manifest.schema.json` (`pack` optional, `packs` list).
- CLI: `labkit start | session | today | timeline | write | learn | settings`.

Labs are not official branches (FINAL §8.3). Santo André is recommended practice;
Manhattan is a proof fixture; a course Lab is teaching practice. None becomes
canon merely by existing.
