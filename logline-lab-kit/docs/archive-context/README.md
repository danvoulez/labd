# Archive context (institutional learning, not authority)

Minilab and Foundation-exploration material from the source fruits is preserved
as *archive context* — meaningful historical/institutional learning, never
promoted to authority (Policy 07). It is NOT copied into this repo; it remains in
the delivery package under `source-fruits/minilab-context/` and
`source-fruits/foundation-exploration/`.

Minilab, Santo André, and Manhattan are not the product root (Operator §13).
