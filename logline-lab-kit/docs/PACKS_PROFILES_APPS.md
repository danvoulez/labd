# Packs, Profiles, Apps

**Basics first; packs complement** (FINAL §15). The kit is useful before any pack.

- **Packs** add practice (did vocabulary, scopes, benches) without changing core
  (A09/A41/A42). Ship: `packs/santo-andre`, `packs/manhattan`,
  `packs/course-starter`. Packs are never canon.
- **Profiles** choose infrastructure (placement, not meaning): `profiles/
  local-only`, `supabase-default`, `postgres-default`, `personal-offline`.
- **Apps** participate under grants: `apps/mcp-server` (generic MCP/app boundary),
  `apps/model-middleware` (ghost), `apps/chatgpt-bridge` (ghost). An app call
  becomes a draft Act (A43); unauthorized actions are blocked (A44). Apps and
  models never own truth; model output is not evidence (A28).
- **Runtimes** execute allowed work and return evidence, never closure
  (`runtimes/local-worker`, `hermes`, `openclaw`, `manhattan`).
