# Scientific Method

The Lab studies; the scientific method is its core bureaucracy (FINAL §9). Every
step is expressible as Acts.

A study bench declares: question, hypothesis, inputs, procedure, expected
observation, success/failure criteria, **receipt scope**, and ghost policy. Running
it produces Acts; an observation becomes **evidence or a ghost** (A18–A21, A31).

- Bench type: `crates/logline-lab-core::bench` (`StudyBench`).
- Schema: `schemas/study-bench.schema.json`.
- Examples: `benches/candidate-promotion/`, `benches/manhattan-l06/`.
- Learning report proposes the next Act: `crates/logline-lab-reports::learning`.
