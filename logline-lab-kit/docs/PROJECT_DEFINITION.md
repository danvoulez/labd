# Project Definition

The controlling definition is `build-pack/final-real-project-doc.md`. This file
is a pointer and a summary.

LogLine Lab Kit is **one project** (`logline-lab-kit`): an installable kit for
forming Labs that study, practice, test, prove, and transmit LogLine through
LogLine Acts. The public objective is to let people instantiate real Labs; the
strategic objective is to make LogLine a **protocol, not a company**.

- Act is the only semantic unit (exactly nine slots).
- The basics ship standalone; packs are additive complements.
- Conformance makes protocol compatibility visible.
- Time, proof, science, and experience serve study.
